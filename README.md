# PulseGuard AI
Predicting blood pressure trends with Streamlit + scikit-learn

Description:-

PulseGuard AI is a lightweight health prediction app built during a hackathon.  
It estimates systolic and diastolic blood pressure based on age, weight, and height,  
using a simple machine learning model deployed with Streamlit Cloud.

Demo Link:-

🚀 [Live Demo](https://pulseguardai-naehaedahcsbfwjacb2kj2.streamlit.app/)

Features:-

- Interactive sliders for age, weight, and height
- Instant blood pressure prediction
- Risk categorization (Normal, Elevated, High Risk)
- Deployed on Streamlit Cloud for easy access
- 
Tech Stack:-

- Python
- Streamlit
- scikit-learn
- pandas, numpy
